# Student Marks Management System

A beginner-friendly full-stack mini project using HTML, CSS, JavaScript and Python Flask.

## Features
- Enter a student's name and marks for three subjects
- Validate marks from 0 to 100
- Calculate total, average, grade and pass/fail status
- Display subject-wise marks
- Responsive layout for laptop and mobile

## Run locally
1. Install Python.
2. Open a terminal in this project folder.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Start the app:
   `python app.py`
5. Open `http://127.0.0.1:5000` in your browser.

## Deploy
This project can be deployed on Render as a Python web service.
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`

## Technologies
Frontend: HTML, CSS, JavaScript  
Backend: Python Flask
